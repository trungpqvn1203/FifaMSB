## 8. Open Questions — All Decided

| #         | Question                                                                                                        | Decision                                                                                                                                                                                                                                              | Status               |
| --------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| **OQ-1**  | `slotsLeft` in BR-P11: slots remaining for **this team** only, or across all teams?                             | **This team only** (`rules.rosterSize - team.pickedCount`)                                                                                                                                                                                            | ✅ Decided (default) |
| **OQ-2**  | `minSalaryInPool`: min salary among all unpicked PlayerSeasons globally, or only positions needed by this team? | **Global minimum** — all ACTIVE, unpicked PlayerSeasons in tournament's allowed seasons                                                                                                                                                                | ✅ Decided (default) |
| **OQ-3**  | Formation validation & squad lock in draft system?                                                              | **Removed** — in FC Online pro draft, team roster is the `DraftPick` rows. Lineup and formations are managed in-game. Replaced by Matches & Bans module.                                                                                             | ✅ Decided (Revision 4)|
| **OQ-4**  | `WAITING → PICKING`: automatic, or second "begin" button?                                                       | **Automatic** — `POST .../draft/start` creates session and immediately transitions to PICKING                                                                                                                                                         | ✅ Decided (default) |
| **OQ-5**  | Snake draft order in Phase 1 scope?                                                                             | **Deferred** — only `LinearOrder` in Phase 1. `DraftOrderStrategy` Protocol defined for future use                                                                                                                                                    | ✅ Decided (default) |
| **OQ-6**  | Phase 1 import: JSON via API, or seed SQL?                                                                      | **CSV via multipart HTTP** (`POST /api/admin/players/import`) + CLI (`external_player_id, name, season_code, position, salary, rating, image_url`)                                                                                                    | ✅ Decided (Revision 4)|
| **OQ-7**  | WebSocket auto-reconnect with exponential backoff?                                                              | **Yes** — frontend reconnects with exponential backoff (500 ms → doubles → cap 30 s)                                                                                                                                                                  | ✅ Decided (default) |
| **OQ-8**  | `version` in DraftState: per-session or global?                                                                 | **Per-session integer stored in `draft_sessions.version`** — starts at 0, incremented under row lock on every state change (`pick`, `skip`, `pause`, `resume`, `complete`, `cancel`).                                                                 | ✅ Decided (default) |
| **OQ-9**  | Can a tournament reference a Season with no PlayerSeason records?                                               | **Multi-season pool: draft start requires ≥ teams * rules.rosterSize ACTIVE cards in allowed seasons (else DRAFT_POOL_TOO_SMALL 422). No season FK on tournament.**                                                                                  | ✅ Decided (Revision 4)|
| **OQ-10** | `salary`: base from dataset, or per-tournament override?                                                        | **Directly from CSV** — `SalaryMapper` is an optional fallback only if missing. Re-import updates salaries via upsert, and `PATCH /api/admin/player-seasons/{id}` allows individual updates when pool is not locked (`POOL_LOCKED`, 422). Helper `docs/tools/calibrate_salary.py` can generate synthetic salaries before import. | ✅ Decided (Revision 4)|
| **OQ-11** | `externalPlayerId`: single global namespace or per-source namespace?                                            | **REQUIRED and globally unique** — rows missing `externalPlayerId` are skipped during import.                                                                                                                                                         | ✅ Decided (default) |
| **OQ-12** | Import: synchronous or async job-based?                                                                         | **Synchronous** — blocks until complete, returns report.                                                                                                                                                                                              | ✅ Decided (default) |
| **OQ-13** | Positions in DB: collapsed or original game strings?                                                            | **Game original position string** (ST, LWB, RWB, etc.) stored without collapsing. No restrictive CHECK constraint. UI groups into filter chips.                                                                                                       | ✅ Decided (Revision 4)|
